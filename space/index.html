Score: Composite = (Accuracy + SpeechBERTScore) / 2, higher is better. Accuracy is 1 − CER: an ASR judge (the best model for each language in the nsanku ASR benchmark) transcribes each clip and the transcript is compared with the sentence that was synthesised. SpeechBERTScore compares the clip with a real recording of the same sentence (microsoft/wavlm-large, layer 6). Every sample comes from ghana-speech-eval; a language with several text sources (domains) is sampled evenly across them.
